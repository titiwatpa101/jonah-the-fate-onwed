# Jonah Guild: The Fate — World Archive

เว็บทดลองแบบ static เปิดอ่านได้ทันที ไม่ต้องล็อกอิน ออกแบบสำหรับ GitHub Pages และการเปิดผ่าน subdirectory ของ repository

## ส่วนที่มีในเวอร์ชันนี้

- แผนที่โลก: คลิกประเทศ เลือกจากปุ่ม หรือใช้คีย์บอร์ด เปิดรายละเอียดเมือง Asher
- คลังเรื่องราว: ค้นหาและกรององค์กร ระบบพลัง ประวัติศาสตร์ และสถานที่
- ตัวละคร: ค้นหา กรองสังกัด เปิดโปรไฟล์ และกดเปิดข้อมูลสปอยล์แยกต่างหาก
- ภารกิจ: ตัวอย่างภารกิจ บันทึกไว้อ่านในเครื่อง และพื้นที่แสดงความคืบหน้าเรื่องราว
- ข่าวสารและอีเวนต์: พื้นที่ประกาศ พร้อมช่องทาง Discord ที่ตั้งค่าได้
- ร่างใบสมัคร: บันทึกใน localStorage และดาวน์โหลดเป็น JSON จำกัดพาสซีฟไม่เกิน 3 บรรทัด และสกิลไม่เกิน 5 บรรทัด

## ข้อจำกัดที่แสดงให้ผู้เล่นทราบ

ใบสมัครยังไม่ส่งไปยังทีมงานและไม่มีระบบผลตรวจจริง ร่างเก็บเฉพาะเบราว์เซอร์/อุปกรณ์ที่ใช้งาน การล้างข้อมูลเว็บไซต์จะลบร่างได้ ปุ่มดาวน์โหลดช่วยเก็บร่างแยกไว้ ภารกิจและกิจกรรมเป็นข้อมูลตัวอย่าง ไม่มีการเข้าร่วมจริงหรือเปลี่ยนสถานะเป็นอนุมัติเอง

ไม่เก็บ Discord ID หรือข้อมูลติดต่อในเว็บทดลอง ไม่มีรหัสผ่าน Token หรือข้อมูลลับในโค้ด

แผนที่ต้นฉบับมีชื่อ Asher ซ้ำ และชื่อ The Fade ในภาพเก่า เว็บแสดงหมายเหตุตำแหน่งที่ถูกต้อง: Asher อยู่ภายใน Almeria ไม่ใช่ประเทศแยก ชื่อประเทศบนภาพที่ข้อมูลยังไม่ยืนยันถูกระบุให้รอการเปิดเผย

## เปิดใช้งาน

เปิด `index.html` ได้โดยตรง หรือเสิร์ฟโฟลเดอร์ด้วย static server ใดก็ได้ ไม่มีขั้นตอน build

## Deploy ผ่าน GitHub Pages

1. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดจากชุดนี้ไปที่ราก repository `titiwatpa101/jonah-the-fate-onwed` บน branch `main` รวมโฟลเดอร์ `.github` (อัปโหลดไฟล์ที่แตก ZIP แล้ว ไม่ใช่อัปโหลด ZIP ทั้งก้อน)
2. เปิด Settings → Pages → Build and deployment → Source แล้วเลือก **GitHub Actions**
3. เปิด Actions → Deploy The Fate to GitHub Pages → Run workflow หากไม่มีการรันอัตโนมัติ
4. เมื่อ workflow สำเร็จ เปิด URL จาก deployment environment `github-pages` หรือ Settings → Pages

หากอัปโหลดผ่านหน้าเว็บแล้วโฟลเดอร์ `.github` ไม่ติดไป สามารถใช้ทางเลือกไม่ต้องมี workflow: Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, Folder: **/(root)** แล้ว Save

การแก้ไฟล์บน `main` จะ deploy ใหม่อัตโนมัติเมื่อเลือกวิธี GitHub Actions และตั้งค่าครบแล้ว

อ้างอิง: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## เปลี่ยนเนื้อหา

- แก้ข้อมูลโลก ตัวละคร ข่าว ภารกิจ และลิงก์ Discord ที่ `data.js`
- เติมลิงก์เชิญจริงใน `config.discordUrl` เช่นลิงก์ที่ทีมงานสร้างเองบน Discord
- แก้หน้าตาที่ `style.css` โครงหน้าอยู่ที่ `index.html` และพฤติกรรมอยู่ที่ `app.js`
- ใช้เฉพาะข้อมูลที่ตั้งใจเผยแพร่ เพราะ repository นี้เป็น public

## การตรวจที่ทำแล้ว

JavaScript ผ่าน `node --check` ทั้งสองไฟล์ HTML มี ID ไม่ซ้ำ หน้าหลักครบ 6 ส่วน และตรวจพบไฟล์อ้างอิงในเครื่องทั้งหมด ยังไม่ได้ทดสอบด้วยเบราว์เซอร์จริงหรือยืนยัน deployment ที่ GitHub

## ต่อยอดระบบจริง

หากต้องรับสมัครและติดตามผลจริง ให้เพิ่ม backend/API และฐานข้อมูล แยกสิทธิ์ผู้ตรวจ พร้อมระบบยืนยันตัวตน การใช้ localStorage ในเวอร์ชันนี้เป็นร่างส่วนตัว ไม่ใช่ฐานข้อมูลหรือระบบอนุมัติ
